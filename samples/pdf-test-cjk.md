```python
# 中文注释的代码块:验证长代码块在页面边界处合理拆分
def 统计词频(文本: str) -> dict:
    """统计给定文本中每个词出现的频率"""
    词频表 = {}
    for 词 in 文本.split():
        词频表[词] = 词频表.get(词, 0) + 1
    return 词频表

if __name__ == "__main__":
    with open("输入.txt", encoding="utf-8") as f:
        内容 = f.read()
    结果 = 统计词频(内容)
    for 词, 频次 in sorted(结果.items(), key=lambda x: -x[1])[:20]:
        print(f"{词}: {频次} 次")
```

段落二:机器学习是人工智能的一个分支。深度学习又是机器学习的一个分支:它使用多层神经网络来学习数据的表示。2012 年 AlexNet 在 ImageNet 竞赛中的突破开启了深度学习时代。

段落五:多模态模型同时处理文本、图像、音频等多种模态,代表系统包括视觉问答、文生图、语音助手等。多模态融合是当前研究热点之一。
