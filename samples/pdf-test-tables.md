## 三、单元格长文本(验证单元格内折行)

| 术语 | 定义 |
|------|------|
| Markdown | 一种轻量级标记语言,设计目标是使用易读易写的纯文本格式编写文档,然后转换为结构化的 HTML/XHTML 文档;广泛用于 README、论坛、博客与技术文档。 |
| 孤行 (Orphan) | 段落被分页后,留在一页底部或顶部的孤立行;良好的排版应通过 orphans/widows 规则避免出现只有一两个字的孤行。 |
| 寡行 (Widow) | 与孤行相对:段落最后一行单独出现在新页顶部的情况;本应用的打印样式将二者均控制在至少三行。 |
| 表头重复 (Header Repetition) | 长表格跨页时,浏览器打印引擎自动在新页重绘 thead 的行为;本测试第二节即用于验证此特性。 |

## 五、表格与代码块交错

| 命令 | 作用 |
|------|------|
| `dotnet build` | 编译解决方案 |
| `dotnet test` | 运行单元测试 |
| `dotnet publish` | 发布单文件可执行程序 |

```sql
-- 长 SQL 块:验证代码块在表格之后仍能合理分页
SELECT o.order_id,
       c.customer_name,
       SUM(oi.quantity * oi.unit_price) AS total_amount,
       COUNT(*) AS item_count
FROM orders o
JOIN customers c ON c.customer_id = o.customer_id
JOIN order_items oi ON oi.order_id = o.order_id
WHERE o.order_date >= '2025-01-01'
  AND o.status IN ('paid', 'shipped', 'completed')
GROUP BY o.order_id, c.customer_name
HAVING SUM(oi.quantity * oi.unit_price) > 1000
ORDER BY total_amount DESC
LIMIT 50;
```

| 输出列 | 类型 | 说明 |
|--------|------|------|
| order_id | int | 订单编号 |
| customer_name | varchar | 客户姓名 |
| total_amount | decimal | 订单总额 |
| item_count | int | 商品种数 |

结尾段落。若以上所有表格在导出的 PDF 中均无裁切、行完整、表头正确重复,则本专项测试通过。
