# Links Target

This file is the *target* of the relative link `links-target.md` in
[link-test.md](link-test.md).

Clicking that link inside the preview is **blocked** — the app shows a warning
dialog instead of navigating away, because only in-page anchors (`#heading`)
are allowed inside the rendered view.

To actually open this file, use File > Open (or drag it into the window).
